7) Tips to improve quality
• Remove long UUIDs/noisy tokens: grep -vE '[0-9a-fA-F]{20,}'
• Keep extensions if you’re targeting files (\.php|\.zip|\.pdf) or filter to only those: grep -E '\.(php|asp|jsp|zip|xml|json)$'
• Limit size for first runs (100–500 lines) to avoid noisy fuzzing: head -n 500 > small.txt
• Decode URL-encoded values with urldecode or python if values contain %2F etc.
